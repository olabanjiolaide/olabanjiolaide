WEARABLE DATA · PYTHON

Wearable Twin Lab

From wearable recordings to inspectable state estimates.

I develop a wearable-data research prototype with sequential replay, stress-like state estimation, predictive uncertainty, and evaluation dashboards.

Pythonscikit-learnStreamlitParticipant-disjoint evaluation

Source repository is private. This page shares the project scope, engineering approach, and limitations.

The problem

A wearable model can appear reliable when recordings from the same person enter both training and evaluation. A useful prototype also needs to show uncertainty, missing intervals, and participant-level failures rather than presenting a single aggregate score.

My contribution

I develop data validation, window extraction, participant-disjoint evaluation, simple classifier baselines, calibration diagnostics, and the Streamlit interface. The workflow includes replay reset boundaries, confidence views, participant review, and report comparison.

Sensor ablations and nested sensor selection are development experiments. Reported reference models remain distinct from exploratory candidates; adding a dashboard does not establish a new physiological model.

Evidence and limitations

The project has a WESAD development evaluation with held-out participants in each outer fold. Those participants have already been inspected during development, so independent validation remains pending. Recorded failures include participants for whom the reference model misses all stress windows; nested sensor selection did not improve the reference results.

Synthetic demonstrations use artificial feature sequences, not realistic physiological simulation. This is an observational engineering prototype, not a validated human digital twin, diagnostic tool, medical device, or live wearable connection.

Dataset files, participant-level reports, and trained models are not published here. Dataset permissions are separate from software licensing.

Next step

Complete visual and interaction checks for the dashboard and strengthen evaluation before making broader reliability claims.
